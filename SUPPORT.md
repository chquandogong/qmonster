# Support

Use the channel that matches the work:

- Setup questions, tmux layout help, badge interpretation, and provider
  behavior: GitHub Discussions.
- Reproducible defects: GitHub Issues with the bug report form.
- Scoped improvements: GitHub Issues with the feature request form.
- Security-sensitive reports: GitHub Security Advisories.

For useful reports, include the Qmonster version/tag, OS, tmux version,
provider CLI version, and redacted evidence. Avoid sharing raw provider
transcripts that contain secrets or private project content.
