# Code of Conduct

Qmonster uses a direct, technical collaboration standard. The project is
small and local-first, but issues, discussions, reviews, and release
threads still need to be useful to the next person reading them.

## Expected Behavior

- Stay specific: include commands, versions, config snippets, fixtures,
  and screenshots when they help reproduce a point.
- Challenge technical claims with evidence and alternatives.
- Keep feedback focused on the work, not the person.
- Respect privacy. Do not post provider transcripts, API keys, local
  paths, or workspace details unless they are intentionally sanitized.

## Unacceptable Behavior

- Harassment, insults, or targeted personal attacks.
- Publishing secrets, private transcripts, or personal data.
- Repeated off-topic posting after a maintainer asks for focus.
- Pressuring maintainers to add destructive automation or unsafe default
  behavior that conflicts with the project contract.

## Enforcement

Maintainers may edit, hide, close, or lock issues and discussions that
violate this standard. Serious security or privacy concerns should be
reported through GitHub private vulnerability reporting when available.
